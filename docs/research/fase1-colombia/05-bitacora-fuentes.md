## 1. Formato estándar para fuentes de la FASE 1 (Colombia)

Cada fuente registra: **ID** (C-xx jurídicas, D-xx deportivas, F-xx heredadas de A1 original), **DEC-xx para decisiones** (para no colisionar con las fuentes D-xx), **título**, **entidad**, **URL completa**, **fecha de publicación**, **fecha de consulta (DD/MM/AAAA)**, **tipo**, **afirmaciones respaldadas**, **limitaciones**, **clasificación** (Hecho verificado / Hallazgo de fuente / Inferencia / Recomendación / Pendiente), **problema/requisito asociado** y **verificación** (nivel de lectura expresado en la propia clasificación y en la columna Limitaciones: `texto íntegro leído` / `extracto` / `sin leer`). No se usan códigos abreviados para no afirmar verificaciones no ejecutadas.

> Regla de honestidad: texto leído íntegramente ≠ extracto de buscador. Donde no hubo íntegra, se declara.
